1. Regras de Permissão Refinadas

Para que o sistema seja seguro e funcional, as regras devem ser aplicadas na camada da View (QuerySet filtering):

    Administrador: Acesso total (visualização, edição e exclusão de todos os registros).

    Escalante: * Visualiza todos os eventos do seu Hospital e Setor.

        Pode editar apenas os eventos criados por ele ou por outros escalantes do mesmo setor.

        Importante: Não visualiza eventos marcados como "privados" por enfermeiros (registros que o enfermeiro fez para si mesmo).

    Profissional (Enfermeiro):

        Pode visualizar os eventos criados pelo Escalante para o setor dele (escala oficial).

        Pode criar/editar seus próprios registros (ex: lembretes de plantão, trocas).

        Privacidade: Registros criados pelo enfermeiro só são visíveis para ele mesmo.

        Trava de Segurança: O enfermeiro só pode lançar eventos para a sua própria Matricula.

class EventoEscala(models.Model):
    # ... (campos anteriores mantidos)
    cor = models.CharField(max_length=7, default='#3498db', verbose_name="Cor Personalizada", help_text="Cor específica para este evento")
    criado_por = models.ForeignKey(User, on_delete=models.CASCADE, related_name='meus_eventos', verbose_name="Criado por")
    # ...

    def clean(self):
        super().clean()
        # Regra de Ouro: Enfermeiro só lança para ele mesmo
        if self.criado_por and hasattr(self.criado_por, 'perfil'):
            if self.criado_por.perfil.tipo_usuario == 'PROFISSIONAL':
                # Verifica se a matrícula escolhida pertence ao usuário logado
                if not self.profissional.perfil or self.profissional.perfil.user != self.criado_por:
                    raise ValidationError("Você só pode registrar eventos para sua própria matrícula.")

1. Ajuste na View (views.py)

Esta lógica garante que cada usuário veja apenas o que lhe é permitido, tratando a hierarquia e a privacidade dos enfermeiros.
Python

from django.db.models import Q
from django.contrib.auth.decorators import login_required

@login_required
def evento_escala_list(request):
    user = request.user
    perfil = user.perfil
    
    # 1. ADMIN: Vê absolutamente tudo
    if perfil.tipo_usuario == 'ADMIN':
        eventos = EventoEscala.objects.all()
    
    # 2. ESCALANTE: Vê o setor dele, mas não vê registros privados de enfermeiros
    elif perfil.tipo_usuario == 'ESCALANTE':
        # Busca a matrícula do escalante para saber o hospital/setor
        matricula = user.perfil.matriculas.first() 
        eventos = EventoEscala.objects.filter(
            hospital=matricula.hospital,
            setor=matricula.setor
        ).exclude(
            criado_por__perfil__tipo_usuario='PROFISSIONAL'
        )
    
    # 3. PROFISSIONAL (Enfermeiro): Vê a escala oficial (Escalante) + Seus próprios registros
    else:
        matricula = user.perfil.matriculas.first()
        eventos = EventoEscala.objects.filter(
            Q(criado_por=user) | # Seus próprios registros
            (Q(setor=matricula.setor) & Q(criado_por__perfil__tipo_usuario='ESCALANTE')) # Escala oficial
        )

    return render(request, 'eventos/list.html', {'eventos': eventos})

2. Ajuste no Formulário (forms.py)

O formulário impede que um enfermeiro lance plantões para outra pessoa.
Python

from django import forms
from .models import EventoEscala

class EventoEscalaForm(forms.ModelForm):
    class Meta:
        model = EventoEscala
        fields = ['data', 'profissional', 'tipo_evento', 'hospital', 'setor', 'cor', 'observacoes']
        widgets = {
            'cor': forms.TextInput(attrs={'type': 'color'}), # Seletor de cor nativo
            'data': forms.DateInput(attrs={'type': 'date'}),
        }

    def __init__(self, *args, **kwargs):
        user = kwargs.pop('user', None) # Recebe o usuário logado da view
        super().__init__(*args, **kwargs)
        
        if user and user.perfil.tipo_usuario == 'PROFISSIONAL':
            # Trava o campo profissional para a matrícula do próprio usuário
            minha_matricula = user.perfil.matriculas.all()
            self.fields['profissional'].queryset = minha_matricula
            self.fields['profissional'].initial = minha_matricula.first()
            # Opcional: Desabilitar para não permitir troca no HTML
            self.fields['profissional'].widget.attrs['readonly'] = True

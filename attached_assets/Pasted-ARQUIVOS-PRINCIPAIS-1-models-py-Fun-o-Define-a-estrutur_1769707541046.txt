ARQUIVOS PRINCIPAIS
1. models.py

Função: Define a estrutura do banco de dados
O que contém:

    EscalaMensal: Cabeçalho da escala (mês, ano, hospital, setor)

    DiaEscala: Dias trabalhados por profissional

    ControleSemanal: Cálculos semanais (CG ANT, CG SM, saldo)

    MapeamentoTurno: Mapeia siglas do Excel para tipos de evento

    TPD: Trabalho em Período de Descanso

    LegislacaoTPD: Regras legais aplicáveis

2. escala_views.py

Função: Controla a lógica do sistema de escalas
Views principais:

    importar_escala(): Importa Excel e processa dados

    lista_escalas(): Lista todas escalas com filtros

    detalhes_escala(): Mostra escala detalhada por profissional

    relatorio_semanal(): Relatórios semanais com cálculos

    exportar_escala(): Exporta para Excel formatado

    dashboard_escala(): Dashboard com estatísticas

3. urls.py (adicional)

Função: Define as rotas/URLs do sistema
Endpoints:

    /escalas/: Lista escalas

    /escalas/importar/: Formulário de importação

    /escalas/<id>/: Detalhes da escala

    /escalas/<id>/relatorio/: Relatório semanal

    /api/saldo-semanal/: API para consulta de saldo

🎨 TEMPLATES (HTML)
4. templates/escala/importar.html

Função: Formulário para upload do arquivo Excel
Controles:

    Seleção de mês/ano

    Seleção de hospital/setor

    Upload de arquivo (.xlsx, .xls)

    Informações sobre estrutura esperada

5. templates/escala/lista.html

Função: Lista todas escalas com filtros
Funcionalidades:

    Filtros por mês, ano, hospital, setor

    Tabela com estatísticas de cada escala

    Botões de ação (ver, relatório, exportar, excluir)

    Paginação

6. templates/escala/detalhes.html

Função: Detalhes completos de uma escala
Contém:

    Calendário visual do mês por profissional

    Abas para navegar entre profissionais

    Cartões com estatísticas

    Controles semanais com saldo

    Botões de impressão e exportação

7. templates/escala/relatorio_semanal.html

Função: Relatórios semanais detalhados
Mostra:

    Tabela com todos controles semanais

    Estatísticas gerais

    Navegação por semana (S1, S2, S3, S4)

    Status de saldo (positivo/negativo)

Função: Configuração do app Django

Função: Controle de versão do banco de dados
Contém:

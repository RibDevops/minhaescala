## Organização da Estrutura de Diretórios

Esta issue tem como objetivo organizar a estrutura de diretórios do projeto, que atualmente é confusa e misturada. A proposta é a seguinte:

- **src/** - Para arquivos principais da aplicação
- **static/** - Para arquivos estáticos, incluindo:
  - **templates/** - Para arquivos de template
  - **js/** - Para arquivos JavaScript
  - **css/** - Para arquivos CSS
  - **img/** - Para imagens
  - **media/** - Para arquivos de mídia

Essa estrutura ajudará a manter o projeto mais organizado e facilitará a manutenção. A definição de uma estrutura consistente é crucial para a escalabilidade e compreensão do projeto.
